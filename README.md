# Gradient Generator

Unique Gradient Generator for Adobe Illustrator.

Generates EPS files (5 per run) of metallic gradient designs — 8 rounded
rectangles per file in a 2x4 grid — with persistent duplicate prevention.
See the pull request for the full package:

- `Long_Term_Gradient_Generator.jsx` — the generator script
- `Installation_Instructions.txt` — setup guide
- `README.txt` — technical reference
